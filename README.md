## 🚀 Featured Projects

### 🧠 [One-Shot Learning on CIFAR-100](https://github.com/bassemr/one-short-learning)
A Siamese network (PyTorch, pretrained ResNet-18) that recognises **classes it has never seen** from a **single example**. Reaches 41.8% accuracy on 10-way 1-shot classification (4× better than chance), with 13 experiments comparing transfer learning, CNNs from scratch, BCE vs contrastive loss and similarity metrics.

`PyTorch` `ResNet-18` `Siamese Networks` `Transfer Learning` `Google Colab` `TensorBoard`

### 🐜 [Ant Trail Problem — AI Agents for a Grid Game](https://github.com/bassemr/Ant-Trail-Problem-)
A partially observable grid game built from scratch, solved and compared with **6 AI approaches**: Monte Carlo Tree Search, Q-Learning, Deep Q-Learning, genetic algorithms, genetic programming, and imitation learning (neural network and decision tree). MCTS solved 10/10 games perfectly on the 3×3 grid.

`Python` `MCTS` `Reinforcement Learning` `Genetic Algorithms` `PyTorch` `scikit-learn` `Pygame`
